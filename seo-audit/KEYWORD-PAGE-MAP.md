## How to use this

1. After deploying, check in Search Console that each page's impressions come from its mapped cluster. If two pages show for the same query, strengthen the mapped page and link to it from the other.
2. When a mapped keyword isn't covered by the page's copy, add it naturally in an H2, the intro or an FAQ answer. Don't add it to every page.
3. When new stock arrives (e.g. a PAX wardrobe), filter the database by model, and those P4 rows become the new product page's keyword list.
4. The classification is automatic with manual spot checks (all P1 rows and samples of P2–P4 were reviewed). Some noise remains; treat a keyword's page as a suggestion.
